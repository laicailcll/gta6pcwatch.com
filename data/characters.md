# characters.csv

## Data scope

Each row represents one named person. The profile context distinguishes a dedicated profile, a shared duo profile, and a mention in another character’s profile. A duo clip can appear in both members’ rows. `not_documented` means the review did not identify an official video for that field.

## Collection date

Sources were reviewed on 2026-11-26, as recorded in the data directory README. The CSV has no date field, so its row-based data cutoff is not stated.

## Source rules

Names and role summaries come from Rockstar’s Only in Leonida character guide. Clip links point to Rockstar’s named character or duo videos. Trailer links are included where verified from Rockstar’s official trailer page. The CSV covers the people named in the guide used for this review.
