# console-to-pc-release-gaps.csv

## Data scope

Each row pairs the first console release with the original Windows release for one title. The gap is `windows_date` minus `first_console_date`, measured in calendar days. The GTA IV Windows date is for North America. `not_stated` means a Windows region was not recorded in the CSV.

## Collection date

Sources were reviewed on 2026-11-26, as recorded in the data directory README. The latest release date in the CSV is 2019-11-05, the Windows launch of Red Dead Redemption 2.

## Source rules

Each row links to the game’s Wikipedia article containing its release dates. Use the first console launch and the original Windows launch for comparison. Later console editions and storefront-specific PC launches can produce different gaps.
