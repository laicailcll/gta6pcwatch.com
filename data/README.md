# GTA 6 PC Watch reference data

These UTF-8 CSV files capture the evidence reviewed on November 26, 2026. Dates use YYYY-MM-DD unless a column contains explanatory text. Read each original source before treating a report as current.

| File | Contents |
| --- | --- |
| [release-claims.csv](release-claims.csv) | Four dated claims with their publishers, source types, and original URLs. |
| [console-to-pc-release-gaps.csv](console-to-pc-release-gaps.csv) | First console and Windows release dates for three earlier Rockstar games. The gap is the Windows date minus the console date in calendar days. The GTA IV Windows date is for North America. |
| [characters.csv](characters.csv) | Eleven names from Rockstar’s Only in Leonida character guide, with the relevant profile and a clip or trailer link where documented. A duo clip can appear in both members’ rows. |
| [cheat-reports.csv](cheat-reports.csv) | Eight button sequences reported by both sources and two additional cross-source disagreements kept outside that pool. Directions use U, D, L, and R for Up, Down, Left, and Right. |

`not_stated` means the cited sources do not state the value. `not_documented` means the review did not identify a named video for that character. `not_tested` means no in-game verification was performed for the dataset. Agreement between reports does not establish compatible game builds or successful in-game use.

The files contain editorial summaries, factual fields, and source links. Publisher text, artwork, videos, and game files remain with their respective owners.
