# cheat-reports.csv

## Data scope

Each row compares a reported console button sequence in Radio Times and Red Bull. U, D, L, and R stand for Up, Down, Left, and Right. `sequence_agreement` records matching inputs, and `sequence_disagreement` records different inputs. The difference field also records conflicting unlock conditions for matching sequences. The reported platform labels give the outlets’ stated scope. `not_stated` marks an unspecified build or first reporter. Every row is marked `not_tested` because no in-game verification was performed.

## Collection date

Sources were reviewed on 2026-11-26, as recorded in the data directory README. The latest article date in the CSV is 2026-11-21, the Red Bull publication date.

## Source rules

The two sequence columns preserve what each original guide reports. Agreement records a match between the reports. It supplies no observation of the code running on a specific build. The date fields refer to publication dates rather than first-discovery dates.
