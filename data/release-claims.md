# release-claims.csv

## Data scope

Each row records a dated claim or announcement and its publisher. The `source_type` field distinguishes official announcements, third-party reports, and editorial guides. Publication date, displayed time zone, and a separately stated update date have their own fields. `not_stated` marks a value the cited page does not state.

## Collection date

Sources were reviewed on 2026-11-26, as recorded in the data directory README. The latest date recorded in `published_date` or `page_updated_date` is 2026-11-25, the GameGPU publication date.

## Source rules

Links go to the original publisher page. Rockstar Newswire supplies the official console announcement. GamesBeat and GameGPU are attributed reporting. Video Games Chronicle’s Steam post is an editorial guide. Check each claim against the source type before citing it.
