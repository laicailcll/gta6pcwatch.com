Why a reported GTA 6 cheat may not work

Published lists disagree about several unlocks and inputs. The comparisons below identify the exact difference to check before repeating a sequence. Each row compares published instructions. Rockstar has not published an official answer to these specific discrepancies in the materials reviewed for this page.

Reported cheat or inputWhat differs between the sourcesWhat this means for the player
$250,000Radio Times adds a fenced-goods target. Red Bull lists story completion.The arrow sequence agrees, while the unlock condition differs. Check the requirement shown for this cheat in your own save.
Cycle WeatherRadio Times adds full map discovery. Red Bull lists story completion.Re-entering the same directions cannot resolve which unlock condition applies to your save. Record the in-game condition first.
Max AmmoAfter the shared seven-input prefix, Radio Times ends Down, Down, Up. Red Bull ends Up, Down, Left.The final three inputs differ. This is a sequence dispute, so the code is outside the agreement table above.
Infinite AmmoRadio Times ends Up, Down, Left. Red Bull ends Down, Down, Down after the same opening.Copying the ending from one guide onto another guide’s named cheat creates an unverified combination. Use the complete entry from the game’s Cheats menu.
Attack ForceTracker lists two Left inputs after Down, Up. The GTA Wiki row contains one Left at that point.The published sequences differ in length. The agreement between Radio Times and Red Bull above leaves this additional variant unresolved.
MTL PumperRadio Times ends Right, Right, Up. Lifehacker ends Left, Up, Left after the shared first five inputs.This difference changes the entered vehicle-spawn sequence. An unlock requirement alone cannot select between the two endings.
Shoulder-button inputGamesRadar+ describes holding both shoulder buttons together. Tracker describes holding the left shoulder button and pressing the right.The setup instruction differs before the D-pad sequence starts. Record the button action separately from the arrows when checking a failure.

These comparisons explain why a single copied sequence can leave two unresolved questions: whether that save has unlocked it and whether the source gives the same inputs as the game. No result in the table above establishes that a code works on a particular patch.

Money, phone numbers, saving, and platform questions

Can I use the money cheat before finishing the story?

The published guides checked here describe a post-story unlock. Their extra conditions differ in the $250,000 row above. An official pre-story bypass has not been published in the Rockstar materials reviewed here. GamesRadar+ unlock instructions · Rockstar Support

Are there phone numbers to dial?

Red Bull describes phone access followed by D-pad inputs and says no dial-in numbers have been found. Rockstar has not published a GTA VI phone-number cheat list in the official material checked for this page. The directional entries above provide the source-backed format currently being compared. Reported phone input method · Rockstar Support

What happens to saves and achievements?

Tracker warns that activating cheats disables saving and achievement or trophy progression. This page has not tested how a later reload, a new session, or a patch changes that behaviour. Save before experimenting and check the game’s own warning before confirming an activation. Tracker’s saving and achievement notice

Does a console code work on Windows?

Rockstar’s GTA VI product page currently names PlayStation 5 and Xbox Series X|S. The reported console entries give no Windows build or keyboard binding. Official Windows cheat controls remain unpublished. Rockstar platform listing

Does a new patch settle a conflict?

A source’s publication date gives the age of its article. A patch-specific answer also needs the game build, the unlocked cheat screen, the entered sequence, and the observed result. Those details are absent from the paired reports above, so this page records the version as not stated and keeps the test results open. Radio Times source · Red Bull source
